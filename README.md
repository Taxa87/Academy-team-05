# Academy-team-05
Проекты группы #5 - интенсив Академии
2 участника, GitHub usernames: Taxa87 и Ardak-777;
Рассматриваемые темы: 
- Помощник по научным исследованиям, 
- Помощник аналитика по крипторасследованиям, 
- ИИ библиотека научных трудов, 
- ИИ по анализу НПА на коррупционные риски,
- ИИ анализ аномалий судебной практики,
- ИИ помощник по правовому мониторингу.
Выбранная тема: ИИ помощник по правовому мониторингу (не утверждена);
• Цель проекта: отслеживание динамики изменений законодательства, обеспечение верховенства права и контроль соблюдения иерархии нормативных правовых актов;
• ожидаемый результат к 12 ноября веб-приложение со следующим **функционалом:** мониторинг законопроектов, выявление норм, затрагивающих конкретную сферу (включая деятельность правоохранительных органов и академии), проверка разрабатываемых и действующих НПА (а также ведомственных приказов) на соответствие нормам Конституции, конституционным законам, кодексам и вышестоящим правовым актам, автоматическое выявление межотраслевых коллизий, противоречий и выхода за пределы нормотворческой компетенции, сравнительный анализ редакций («было/стало»), изучение международного опыта регулирования, оценка влияния изменений на внутренние процессы, автоматическая генерация дайджестов изменений, таблиц соответствия, юридических заключений о выявленных противоречиях вышестоящему законодательству, проектов приказов о внесении изменений во внутренние регламенты и рабочие программы академии, подготовка запросов в ГО; **Результат использования веб-приложения:**своевременная адаптация внутренних регламентов под новые законы, предотвращение принятия и применения норм, противоречащих Конституции и вышестоящим правовым актам, устранение правовых коллизий, минимизация правовых рисков и автоматизация актуализации учебно-методической и ведомственной базы.
• текущий этап: проведено углубленное исследование и ближайший шаг: утверждение темы;
• ссылку на демонстрацию, когда она появится.
